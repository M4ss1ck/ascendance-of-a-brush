# The UI theme borrows a mood, not a franchise

The app's look is inspired by the owner's favorite series about books and printing: a deep blue (`#2c4a8f`) bookcloth wall, gilt tooling, parchment, a wax seal for the seed and ribbon bookmarks. The type is Mononoki for the interface and Metal for the few small labels, both self-hosted through `@fontsource` (no third-party requests, ADR-0001).

The series lends colors, materials and atmosphere only. The app never uses its names, characters, logos, quotes or artwork, and the UI does not mention it.

## Considered Options

- **A literal fan theme** with the series' characters or art. Rejected: the app is public, and that material is not ours to redistribute.
- **The usual serif-revival pairing** (IM Fell English, Cormorant Garamond). Rejected as a generic default that does not set this app apart.

## Consequences

Brush picks show engine-drawn strokes filling a swatch, never image previews or one lone stroke. Small text is kept only where it does a job; slogans and decorative captions are cut.
