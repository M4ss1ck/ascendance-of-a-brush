How the painting is planned

  • Each layer halves the brush, blurs the source to that brush size (Gaussian, sigma = half the brush radius) and places a stroke only in grid cells whose average color error is above the threshold, at the worst pixel in the cell. The first layer always covers everything.
  • Edge-aware curve: grows both ways from its start point along the edge flow. Before each half step it checks the source color under the center and at both sides of the brush, and stops if any of them is further than the color tolerance from the start color. It paints the average source color along its path.

Why small features disappeared

  • The finest reference was blurred too hard. Three box-blur passes of radius r give sigma = sqrt(r(r+1)), so the old radius of R/2 gave sigma 2.4 for a 3 px brush instead of 1.5, and the lips were gone from the target before any paint went down. Fixed for every panel.
  • Even with the right target, a 3 px brush paints a 4 px wide stroke, and a mouth line at 480 px wide is about 1 px thick and 8 px long. Raising the working size or adding a fifth layer (1.5 px brush) is how these brushes reach small features.

Scores

  • Line error is the mean color distance on thin lines and small spots (found with a difference of Gaussians on brightness). It measures whether features like lips survive. Edge error covers the 15% of pixels with the strongest gradients. Both are measured against the sharp source. Overall error uses a lightly blurred source so brush texture isn't punished.
  • Replay repaints from the saved stroke list alone and compares pixel hashes. Hashes are stable in one browser; canvas antialiasing differs between engines.
